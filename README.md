# Mario Nova

HTML, CSS ve JavaScript kullanılarak geliştirilmiş, neon temalı profesyonel Mario tarzı platform oyunu.

## Özellikler

- Modern neon arayüz ve cam efektiyle yeniden tasarlanmış HUD
- Özel fizik motoru, çift zıplama ve sprint mekaniği
- Parallax skyline, yıldızlı arka plan ve parçacık efektleri
- Toplanabilir parlayan yıldız-coins sistemi ve skor takibi
- Duraklatma, devam ettirme ve hızlı yeniden başlatma kontrolleri

## Başlangıç

1. Depoyu yerel ortamınıza klonlayın.
2. `index.html` dosyasını tarayıcınızda açın.
3. Klavye kontrolleri ile Mario Nova dünyasında koşun!

### Kontroller

- `A` / `D` veya `←` / `→`: Hareket
- `W` / `↑` veya `Boşluk`: Zıpla / çift zıpla
- `Shift`: Sprint
- `R`: Sahnayı sıfırla

> Oyun tamamen tarayıcı üzerinde çalışır, ek bağımlılık gerektirmez.
